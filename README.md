# 🌲 조성현 합격 플래너 (For-SeoungHyunJo)

> 5급 기술고시(산림자원직)를 준비하는 친구 **조성현**을 위한 학습 플래너 데스크톱 앱

공부할수록 나무가 자라고, 큰나무가 모여 숲이 됩니다.
장기 수험 생활을 꾸준히 이어갈 수 있도록 응원·기록·시각화에 초점을 맞춘 앱입니다.

### 🌳 나무 성장 시스템
공부 시간이 쌓이면 나무가 단계별로 자랍니다.
**다음에 어떤 나무가 될지는 비밀** — 목표 시간을 채우고 직접 확인하세요. 🤫

### ❌ 오답노트 (v1.3 신규)
틀린 문제를 등록하면 망각곡선에 맞춰 **1·3·7·14·30일** 후 자동으로 복습 일정이 잡힙니다.
- **퀴즈 모드**: 문제만 먼저 보여주고 정답을 가립니다 → 풀이 후 정답·해설 공개 → **맞춤/틀림** 평가
- **틀리면 1단계로 리셋**되어 다시 5단계를 거칩니다 (에빙하우스 정통)
- 풀이 시간·오답 유형(개념/실수/시간부족/찍기/기타)·이미지 첨부·자유 태그 지원
- 홈에 "오늘 복습 N개" 노란 칩이 자동 표시되며, 통계 화면에는 **과목별 약점 점수**가 누적됩니다

### ☕ 쉼 (v1.5 신규)
공부가 힘들 때 잠깐 들러서 한숨 돌리는 페이지. 두 개의 탭으로 구성됩니다.

- 🧡 **내 사람들** — 가족·친구 사진을 올려두고 그리드/라이트박스로 감상. 캡션 인라인 편집·삭제. 사진은 자동으로 압축(최대 1200px)되어 데이터 파일에 함께 저장됩니다.
- 🎨 **취미** — 이름·이모지·메모로 취미를 등록하고 **"오늘 했어요 ✨"** 한 번 클릭으로 마지막 한 날을 기록. 7일 이상 안 한 항목은 옅은 톤 + *"오랜만이네요 🌱"* 라벨로 살짝 알려줘요.

### 🔗 자주 가는 곳 — 카테고리 편집 (v1.5)
사이드바 카테고리 카드의 **⚙️** 버튼으로 카테고리를 일괄 편집할 수 있습니다.
- 이름·색상 변경, 순서 ↑↓, 삭제, 새 카테고리 추가
- 카테고리 이름을 바꾸면 해당 카테고리의 **모든 사이트도 자동으로 새 이름**으로 정리됨
- 카테고리를 삭제하면 그 카테고리의 사이트는 **기타**로 이동

### 🍅 포모도로 모드 (v1.6 신규)
학습 타이머의 세 번째 탭. PSAT 같은 시간 압박형 시험 대비 + 집중력 훈련용.
- **25분 집중 + 5분 짧은 휴식** 자동 순환, 4사이클마다 **긴 휴식 15분**
- 각 단계 끝나면 자동 전환 + 토스트 알림. ⏭ 단계 종료로 즉시 스킵 가능
- 완료한 집중 사이클은 **일반 학습 세션**으로 기록되어 통계·플래너 타임라인·나무 성장에 합산
- 탭 이동·앱 재시작에도 진행 상태 유지
- 시간은 **설정 → 🍅 포모도로 설정** 에서 조정 가능

### 🃏 플래시카드 (v1.6 신규)
한국사 연도·전공 용어 같은 단순 암기에 가벼운 도구. 오답노트보다 부담 없이 쓸 수 있어요.
- 앞면(질문) / 뒷면(정답) / 과목 태그
- 학습 모드: 카드 클릭 → 뒷면 공개 → **😎 맞춤 / 😅 모름**
- **3연속 맞춤** 시 자동 마스터 분류 (학습 큐에서 빠짐). 🔁 버튼으로 다시 학습 큐로 되돌릴 수 있음
- 모름 클릭 시 연속 카운트 리셋
- 과목별 필터, 학습 중 / 마스터 / 전체 탭

### 📋 학습 시작 체크리스트 (v1.6 신규)
학습 타이머 ▶ 시작 버튼 위에 작은 체크리스트가 떠요. 매번 체크하면서 집중 진입 의식을 만들어요.
- 기본 항목: **💧 물 준비 / 📱 휴대폰 멀리 / 📚 자료 준비**
- 항목은 **설정 → 📋 학습 시작 체크리스트** 에서 자유롭게 추가·삭제·순서 변경
- 체크 상태는 매번 새로 시작 (저장하지 않음 — 매일 다시 점검하는 의식)

### 🔍 통합 검색 (v1.6 신규)
앱 안의 모든 자료를 한 번에 가로질러 검색해요. 메모가 쌓일수록 가치 커지는 기능.
- **검색 대상**: 과목 메모(제목·본문) / 오답노트(문제·정답·해설·태그) / 자주 가는 곳(이름·URL·설명) / 플래시카드(앞면·뒷면) / 하루 돌아보기 메모 / 취미 이름·메모 / 사진 캡션
- 매칭된 부분은 **노란색 강조**, 긴 본문은 검색어 주변만 잘라서 표시
- 결과는 **출처별로 그룹**, 각 그룹의 **"이 화면 열기 →"** 버튼으로 원본 화면으로 점프
- 대소문자 무시, 부분 일치

## 🚀 설치 및 실행 (사용자용)

설치 프로그램 없이 zip 파일 하나로 끝나는 휴대용 앱이에요.

### 1️⃣ 어디에 저장할까?

- ✅ **권장 위치**: `C:\Seonghyeon Planner\` 같은 **C 드라이브 루트에 직접 만든 폴더**
  또는 `C:\Apps\Seonghyeon Planner\` 같은 본인이 만든 일반 폴더
- ❌ **피해야 할 위치 1**: `C:\Program Files\` 안 — 관리자 권한이 필요해서 **자동 업데이트가 실패**합니다
- ❌ **피해야 할 위치 2**: OneDrive · Dropbox · Google Drive 같은 **동기화 폴더 안**
  — 동기화 중 파일이 잠겨서 자동 업데이트가 옛 버전으로 되돌아갈 수 있어요

### 2️⃣ 다운로드한 zip 을 적용하는 방법

1. **GitHub Releases** 페이지([최신 릴리스 보기](https://github.com/sangheon55/For-SeoungHyunJo/releases/latest))에서 최신 `v1.X.X.zip` 을 받습니다.
2. 받은 zip 을 **우클릭 → 압축 풀기(또는 "여기에 풀기")** 로 위에서 정한 위치에 풉니다.
   예: `C:\Seonghyeon Planner\` 안에 `Seonghyeon Planner-win32-x64` 폴더가 통째로 들어갑니다.
3. 그 폴더 안으로 들어가서 **`Seonghyeon Planner.exe`** 를 더블클릭하면 앱이 켜져요.
4. 설치 과정·인터넷 연결 없이 바로 사용할 수 있어요.

> 🛡 **처음 실행 시 "Windows 의 PC 보호" 경고가 뜨면**
> "추가 정보" 글자를 클릭 → **[실행]** 버튼이 나타나요. 누르면 앞으로는 안 떠요.
> (개인 개발자가 만든, 서명 비용을 안 들인 앱이라 나타나는 정상 안내입니다.)

### 3️⃣ 바로가기 만들기 (한 번만 설정해 두면 편함)

매번 폴더를 열어서 exe 를 찾지 않아도 되도록 단축 진입로를 만들어 두세요.

**🖥 바탕화면 바로가기**
1. `Seonghyeon Planner.exe` 를 **우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기**
2. 바탕화면에 아이콘이 생기면 더블클릭으로 바로 실행

**📌 작업 표시줄 고정 (가장 추천)**
1. `Seonghyeon Planner.exe` 를 **우클릭 → 작업 표시줄에 고정**
2. 화면 아래쪽 작업 표시줄에서 한 번 클릭으로 실행

**🪟 시작 메뉴 고정**
1. `Seonghyeon Planner.exe` 를 **우클릭 → 시작 화면에 고정**
2. Windows 키 → 시작 메뉴에서 아이콘 검색 / 클릭

> 💡 앱 폴더 위치를 옮기면(C: 다른 폴더로 등) 기존 바로가기는 끊깁니다.
> 옮긴 뒤에는 위 단계로 새 바로가기를 다시 만들어 주세요.
> (앱 폴더는 한 번 정한 위치에서 그대로 두는 게 가장 편해요.)

## 🔁 업데이트 방법

> ⚠️ **앱 내 자동 업데이트 기능은 현재 미해결 상태입니다.**
> Windows Defender 의 AMSI / ASR 보안 정책이 업데이트 스크립트를 차단하는 문제를
> `.bat → PowerShell → EncodedCommand → cmd.exe` 순으로 반복 시도했지만 완전히 해결하지 못했어요.
> **수동 업데이트가 가장 확실한 방법**이라 이 방식을 권장합니다.

### 📦 수동 업데이트 (권장)

1. **GitHub Releases** 에서 최신 zip 다운로드 → [최신 릴리스 보기](https://github.com/sangheon55/For-SeoungHyunJo/releases/latest)
2. 현재 앱이 켜져 있다면 **완전히 종료** (창 닫기 + 작업 표시줄 아이콘도 닫기)
3. 받은 zip 을 **우클릭 → 압축 풀기**
4. 압축 풀린 폴더(`Seonghyeon Planner-win32-x64`) 를 **기존 앱 폴더 위치에 덮어쓰기**
   또는 기존 폴더를 통째로 지우고 새 폴더로 교체
5. 새 폴더 안의 `Seonghyeon Planner.exe` 를 더블클릭해서 실행
6. (선택) 바뀐 `.exe` 경로로 [바로가기를 다시 만들어](#3️⃣-바로가기-만들기-한-번만-설정해-두면-편함) 두면 편해요

> ✅ **데이터는 안전합니다.** `%AppData%\Seonghyeon Planner\planner-data.json` 에 별도 저장되어
> 앱 폴더를 통째로 교체해도 오답·메모·타이머·통계 기록은 **그대로 유지**됩니다.

### 🔄 (참고) 앱 내 자동 업데이트 — 미해결

설정 → **🔄 앱 업데이트** 메뉴는 남아 있지만 보안 정책 차단으로 정상 동작하지 않을 수 있어요.
**[업데이트 확인]** 까지는 동작하지만, **자동 설치 단계가 보안 정책에 막힐 수 있습니다.**
그 경우 같은 화면의 **[GitHub Releases 페이지 열기]** 로 zip 을 받아 위의 수동 업데이트로 진행해 주세요.

## 💾 데이터 관리

- 모든 기록은 앱 폴더가 아닌 **고정 경로 파일**에 저장됩니다:
  ```
  C:\Users\<사용자>\AppData\Roaming\Seonghyeon Planner\planner-data.json
  ```
- 앱(.exe)을 **새 버전으로 교체해도 데이터는 그대로 유지**됩니다.
- 새 버전에서 기능이 추가돼도 기존 데이터에 자동으로 호환됩니다.
- 앱 내 **설정 → 데이터 내보내기 / 가져오기**로 다른 PC로 옮길 수 있습니다.
