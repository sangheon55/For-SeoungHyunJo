# 🌲 조성현 합격 플래너 (For-SeoungHyunJo)

> 5급 기술고시(산림자원직)를 준비하는 친구 **조성현**을 위한 학습 플래너 데스크톱 앱

공부할수록 나무가 자라고, 큰나무가 모여 숲이 됩니다.
장기 수험 생활을 꾸준히 이어갈 수 있도록 응원·기록·시각화에 초점을 맞춘 앱입니다.

---

| 화면 | 설명 |

| 📝 과목 메모 | 과목별 개념·암기 포인트 메모 작성/수정/삭제 |

### 🌳 나무 성장 시스템
공부 시간이 쌓이면 나무가 단계별로 자랍니다.
**다음에 어떤 나무가 될지는 비밀** — 목표 시간을 채우고 직접 확인하세요. 🤫

### ❌ 오답노트 (v1.3 신규)
틀린 문제를 등록하면 망각곡선에 맞춰 **1·3·7·14·30일** 후 자동으로 복습 일정이 잡힙니다.
- **퀴즈 모드**: 문제만 먼저 보여주고 정답을 가립니다 → 풀이 후 정답·해설 공개 → **맞춤/틀림** 평가
- **틀리면 1단계로 리셋**되어 다시 5단계를 거칩니다 (에빙하우스 정통)
- 풀이 시간·오답 유형(개념/실수/시간부족/찍기/기타)·이미지 첨부·자유 태그 지원
- 홈에 "오늘 복습 N개" 노란 칩이 자동 표시되며, 통계 화면에는 **과목별 약점 점수**가 누적됩니다

## 🚀 설치 및 실행 (사용자용)

1. 배포받은 `Seonghyeon Planner-win32-x64` 폴더의 압축을 풉니다.
2. 폴더 안의 **`Seonghyeon Planner.exe`** 를 더블클릭합니다.
3. 설치 과정·인터넷 연결 없이 바로 사용할 수 있습니다.

> 처음 실행 시 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행** 을 누르세요.
> (서명되지 않은 개인 앱이라 나타나는 정상적인 안내입니다.)

자세한 사용·전달 방법은 [사용법.md](사용법.md) 참고.

## 🔁 업데이트 방법

### 📥 사용자(조성현)가 새 버전 받았을 때

1. 현재 앱이 **켜져 있다면 완전히 종료**합니다.
2. 새로 받은 `Seonghyeon Planner-win32-x64` 폴더 압축을 풉니다.
3. **기존 앱 폴더는 통째로 지우거나, 새 폴더로 그냥 덮어 쓰기** 해도 됩니다.
4. 새 폴더 안의 `Seonghyeon Planner.exe`를 더블클릭하면 끝.

> ✅ **기존 기록은 그대로 유지됩니다.** 데이터는 앱 폴더가 아니라 PC의 별도 경로에 저장되기 때문입니다.
> (`%AppData%\Seonghyeon Planner\planner-data.json`)

### 🛠 개발자가 새 버전 배포할 때

```bash
# 1) package.json의 "version" 을 올린다 (예: 1.3.0 → 1.4.0)
# 2) 빌드
npm run dist

# 3) release\Seonghyeon Planner-win32-x64\ 폴더가 새로 생성됨
#    이 폴더를 zip으로 압축해서 친구에게 전달
```

빌드 결과: `release/Seonghyeon Planner-win32-x64/Seonghyeon Planner.exe`

> 새 버전에서 데이터 스키마가 추가돼도 `mergeDefaults`가 기존 JSON을 자동 보강하므로
> 기존 사용자 데이터는 **삭제·재설치 없이 호환**됩니다. (v1.3에서 추가된 `wrongAnswers`도 자동 빈 배열로 초기화)

## 🛠 개발 / 빌드

```bash
npm install      # 의존성 설치 (최초 1회)

npm run dev      # 브라우저에서 개발 미리보기
npm run app      # 데스크톱 앱 창으로 실행
npm run build    # 웹 자산만 빌드 (dist/)
npm run dist     # Windows 배포용 폴더 전체 빌드 (release/)
```

**기술 스택**: Vite · React 18 · Electron (electron-packager 패키징)

## 💾 데이터 관리

- 모든 기록은 앱 폴더가 아닌 **고정 경로 파일**에 저장됩니다:
  ```
  C:\Users\<사용자>\AppData\Roaming\Seonghyeon Planner\planner-data.json
  ```
- 앱(.exe)을 **새 버전으로 교체해도 데이터는 그대로 유지**됩니다.
- 새 버전에서 기능이 추가돼도 기존 데이터에 자동으로 호환됩니다.
- 앱 내 **설정 → 데이터 내보내기 / 가져오기**로 다른 PC로 옮길 수 있습니다.
